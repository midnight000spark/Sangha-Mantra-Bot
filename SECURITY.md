# Безопасность

Не публикуйте токены, ключи резервных копий, реальные env-файлы, базы или журналы участников в issues и pull requests. Для описания проблемы используйте минимальный воспроизводимый пример с вымышленными данными.

Настраивайте административный allowlist, отдельные TEST/production ресурсы и секрет webhook. Не отключайте проверки идентичности базы и кампании. Telegram ID и история административных действий — операционные данные с ограниченным доступом.

При подозрении на раскрытие credentials отзовите и замените их. Удаление файла из последнего коммита не удаляет его из Git-истории.
