# Бот коллективного накопления мантр

Telegram-бот на TypeScript для Cloudflare Workers и D1. Участники пишут количество выполненных повторений в группе; бот учитывает вклад и публикует ежедневный общий отчёт. Интерфейс и сообщения — на русском языке.

Это очищенная публикация исходников. Все идентификаторы инфраструктуры, бота, чатов и администратора в конфигурации — **вымышленные примеры**. Эта копия не управляет существующим развёртыванием.

## Возможности

- Учёт одного самостоятельного положительного ASCII-числа из текстового сообщения: `1000`, `1000🙏`, `Начитал 108 мантр`.
- Защита от повторной доставки; редактирование заменяет прежний вклад. Неоднозначные версии отправляются на проверку.
- Медиа, подписи к ним, пересылки, сообщения ботов и сообщения от имени чата не учитываются. Числа внутри URL, code и других исключённых entities пропускаются.
- Исправления администратором через личку: ссылка на исходное сообщение → текущее значение → «Исправить» / «Отменить» → новое число → причина. `/recent` показывает последние 20 записей. Права проверяются при каждом действии.
- Неизменяемые снимки ежедневных отчётов, журнал исправлений, контроль неопределённого результата отправки и восстановления.
- Зашифрованные резервные копии с проверкой восстановления в отдельную SQLite.

**Правило группы:** обычные числа означают новую практику. Фраза `Мне 35 лет` тоже даст +35: бот не определяет намерение автора. `1 000`, дроби, даты, несколько чисел и превышение лимита отклоняются. Удаление сообщения не отменяет вклад; используйте административное исправление.

## Локальная проверка

Требуются Bun 1.4.4 и Linux для локальных workerd/D1-проверок. Зависимости закреплены в `bun.lock`.

```bash
bun install --frozen-lockfile
bun run check
bun run build
bun run backup:drill
```

Проверки используют локальные базы и имитацию Telegram. `build` выполняет dry-run, без публикации Worker. CI выполняет эти же локальные проверки; секреты и cloud-доступ ему не нужны.

Локальный HTTP-сервер:

```bash
cp .dev.vars.example .dev.vars.test
bun run migrate:local
mkdir -p test-results
bun scripts/test-target.ts --local --sql > test-results/local-enrollment.sql
bunx --no-install wrangler d1 execute DB --local --env test --file test-results/local-enrollment.sql
bun run dev
```

Пример токена предназначен только для локальной работы. Внешние отправки с ним не работают.

## Устройство

`src/` — обработчик webhook/Cron, парсер, учёт, отчёты, административный диалог. `migrations/` — схема D1. `scripts/` — инструменты проверки и эксплуатации. `tests/` — модульные, интеграционные и локальные D1/runtime-проверки.

Общая сумма вычисляется через SQL SUM действующих вкладов. Исходный текст сообщений и имена участников не сохраняются; Telegram ID и журналы действий нужны для учёта и сверки. Они остаются чувствительными операционными данными.
