# Исправление накоплений

В личном диалоге с ботом разрешённый администратор отправляет ссылку на исходное сообщение группы. Поддерживаются публичные ссылки `https://t.me/example_group/27` и ссылки закрытой супергруппы `https://t.me/c/1234567891/27`.

Бот находит запись в собственной базе, показывает текущее значение и кнопки «Исправить» / «Отменить». Для исправления нажмите кнопку, ответьте новым числом, затем укажите причину. `/cancel` отменяет незавершённый диалог.

`/recent` показывает последние 20 накоплений с кнопками выбора. Это удобно, если исходную ссылку трудно найти. Пересылка сообщения не используется как надёжная идентификация оригинала.

Авторизация проверяется на каждом действии. Операции диалога и исправления сохраняются в журнале; повторы не создают повторное исправление. Существующие команды ручного исправления и сверки сохранены в `src/admin.ts`.

Собственные отчёты и сообщения других ботов не учитываются как практика. Для корректировки вклада после удаления исходного сообщения используйте административные средства: Telegram не сообщает боту обо всех удалениях.
