# Границы публикации

Публикация подготовлена как отдельный репозиторий с новой историей. История рабочего репозитория и её commit metadata не переносились.

Включены исходники, миграции схемы, тесты, эксплуатационные скрипты, lockfile, конфигурация с вымышленными ID и общая документация. Замены инфраструктурных идентификаторов согласованы с проверками изоляции и тестами. Реальные ссылки на группы и username бота заменены примерами.

Исключены локальные `.secrets/`, env-файлы, авторизация инструментов, базы, резервные копии, логи, эксплуатационные результаты, частные инструкции, переписка, исторические handoff/acceptance-документы и scheduled workflows. Пример `.dev.vars.example` содержит только локальные фиктивные значения.

Перед публикацией выполняются проверка на известные частные идентификаторы и значения секретов, Gitleaks для файлов и новой Git-истории, а также локальные проверки очищенной копии. Проверки уменьшают риск утечки, но не являются гарантией отсутствия любых неизвестных чувствительных сведений.

Дальнейшие изменения публикуйте только из этой очищенной копии после повторной проверки diff и секретов. Не добавляйте исходный рабочий репозиторий как источник истории и не переносите его ветки или теги.

## Проверенная исходная публикация

- `bun run check`: typecheck и 157 тестов, 640 assertions, ошибок нет.
- `bun run build`: локальная dry-run сборка TEST, без cloud-развёртывания.
- `bun run backup:drill`: локальное восстановление, контроль целостности, отклонение повреждённого архива и неверного ключа.
- Сканирование Gitleaks 8.30.1 и сравнение с известными частными идентификаторами/credentials выполняются до отправки исходного коммита. Данные проверок и частный список замен не публикуются.


## Публикация maintenance

Maintenance перенесён отдельным публичным коммитом поверх очищенной истории. Включены исходники, миграция0007, регрессионные тесты и обезличенные операционные шаблоны. Частные task/handoff/status/snapshot-документы заменены общей инструкцией maintenance и продолжения; исходные live receipts не включены. Production cutoff SQL заменён самостоятельным примером с вымышленными ресурсами, без данных о реальных исправлениях и согласованиях. Новые TEST bot/database identifiers также вымышленные и согласованы с guards.

Перед отправкой ветки повторно проверяются именно очищенные файлы, тесты и вся достижимая публичная история. Live-результаты закрытого окружения не выдаются за проверку нового пользовательского развёртывания или подтверждение CPU.

Проверки очищенного maintenance-кандидата: typecheck и 186 тестов / 808 assertions PASS; dry-run build и локальный encrypted backup/restore drill PASS. Это результаты очищенного набора исходников; cloud-конфигурация в публикации содержит вымышленные значения.
